개인정보처리방침

본 방침은 운영자 sumoonho-spec의 개인용 YouTube Shorts Uploader에 적용됩니다.

이용 목적과 범위

본 도구는 운영자 본인의 채널에 동영상을 업로드하기 위해 Google OAuth 인증 정보, 선택한 영상 파일, 제목·설명·공개 상태 등 업로드 정보를 사용합니다. 요청 권한은 youtube.upload이며 다른 사용자의 정보를 수집하는 서비스로 운영하지 않습니다.

데이터 전송과 보관 원칙

업로드에 필요한 영상과 메타데이터는 Google/YouTube에 전송됩니다. 인증 토큰은 업로드 및 인증 갱신 목적으로만 사용하며, 운영자가 관리하는 실행 환경에서 접근을 제한하여 보관해야 합니다. 인증 JSON, 비밀키, 토큰, 비공개 영상은 이 공개 웹사이트나 공개 저장소에 게시하지 않습니다.

Google 사용자 데이터는 광고, 판매, 대여, 타인에 대한 제공 또는 범용 AI 모델 학습 목적으로 이용하지 않습니다. Google API로 받은 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

삭제와 권한 철회

운영자는 Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 사용을 중단하면 실행 환경에 보관한 토큰과 불필요한 로컬 데이터를 삭제해야 합니다. 이미 업로드한 영상은 YouTube Studio에서 별도로 관리하거나 삭제할 수 있습니다.

안내 웹사이트

이 안내 사이트에는 분석 스크립트, 광고, 로그인 또는 정보 입력 양식을 넣지 않습니다. 호스팅 제공자 GitHub는 서비스 운영을 위해 접속 정보를 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다. YouTube에 전송된 정보에는 Google 개인정보처리방침이 적용됩니다.
